# Workshop — Облік проєктів майстерні

**Тема проєкту:** Облік проєктів майстерні: вироби, матеріали, етапи; собівартість і строки виготовлення.

Вебзастосунок призначений для автоматизації обліку виробничих процесів у ремісничій чи столярній майстерні. Система дозволяє вести перелік замовлених виробів, контролювати витрати матеріалів, відстежувати етапи виконання робіт, а також розраховувати собівартість продукції та дотримання строків виготовлення.
