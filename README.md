# Workshop — Облік проєктів майстерні

**Тема проєкту:** Облік проєктів майстерні: вироби, матеріали, етапи; собівартість і строки виготовлення.

Вебзастосунок призначений для автоматизації обліку виробничих процесів у ремісничій чи столярній майстерні. Система дозволяє вести перелік замовлених виробів, контролювати витрати матеріалів, відстежувати етапи виконання робіт, а також розраховувати собівартість продукції та дотримання строків виготовлення.

## Особливість проєкту

Застосунок підтримуватиме автоматичне нагадування та візуальне позначення записів, що потребують уваги майстра. Система аналізуватиме планову дату завершення (`DeadlineOn`), фактичний статус виконання (`Stage`) та співвідношення собівартості матеріалів до ціни продажу (`MaterialCost` і `SalePrice`), щоб виділяти замовлення, строк здачі яких наближається або вже прострочений, а також нерентабельні проєкти. Це дозволить вчасно реагувати на затримки виробництва та уникати збитків або зриву дедлайнів.
