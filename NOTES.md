# Робочі нотатки

## ЛР 2: Модель предметної області(`WorkshopProject`)

- **`decimal` для `MaterialCost` і `SalePrice`**: обрано для точного подання грошових сум без похибок двійкового округлення, характерних для `double` і `float`.
- **`DateOnly` та `DateOnly?` для `StartedOn`, `DeadlineOn` і `CompletedOn`**: для контролю строків виготовлення виробів потрібна лише календарна дата без часу доби. Тип із підтримкою `null` (`DateOnly?`) для `CompletedOn` дозволяє залишати поле порожнім, поки замовлення ще виконується.
- **`string` та `string?`**: обов’язкові текстові властивості (`ProductName`, `MaterialsSummary`) оголошено як `string` з початковим значенням `""`, а необов’язкові примітки (`Notes`) — як `string?` (дозволяє `null` за активного режиму `<Nullable>enable</Nullable>`).
- **`enum ProjectStage`**: використано тип-перелік замість звичайного рядка, оскільки життєвий цикл виробу в майстерні має фіксований набір етапів (`Draft`, `Materials`, `Production`, `Finishing`, `Completed`), і `enum` унеможливлює помилки введення довільного тексту.
